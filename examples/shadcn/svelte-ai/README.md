# Svelte AI shadcn example

This private example streams an AI-generated JSON Render specification through the first-party
Svelte shadcn integration. It provides a framework comparison and is not published to npm.

Copy `.env.example` to `.env`, provide an OpenAI API key, and keep that file uncommitted:

```bash
pnpm --filter @examples/shadcn-svelte-ai dev
```

The example runs on `http://localhost:3103`. Never place real credentials in issues, logs,
screenshots, or committed example files.
